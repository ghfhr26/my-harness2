# 하네스 게이트 (R5)

모든 조건은 판정 스크립트(`scripts/gate.py`)가 센다. 통과 = 아래 조건의 위반 합계 0건.

## 판정에 쓰는 데이터
- G1, G2: 실행 폴더의 파일.
- G3, G4, S5: 판정할 때마다 스크립트가 Figma REST API로 실행 페이지의 노드를 직접 읽는다. 에이전트가 적은 값으로는 판정하지 않는다.
- Figma를 읽지 못하면(G0-5) G3, G4, S5는 미통과다.
- 프레임 이름: 키스크린은 `key/<화면명>`, 완성 시안은 `screen/<화면명>`. 실행 페이지 최상위에 둔다.
- ★A·★B를 Figma에서 세기 위한 레이어 이름 규칙은 `docs/harness-roles.md`에 있다.

## 무결성 (모든 게이트 앞에서 검사)
| ID | 조건 |
|---|---|

## G3 사람 컨펌 ★ (유일한 사람 승인)
1. S3가 끝나면 멈추고 Figma 링크를 보여준다.
2. 실행자가 `컨펌 승인` 또는 `컨펌 반려 <visual|structure|direction> <메모>`를 입력한다.
3. `approval.json`에 결과, 사유 코드, 컨펌자 이름, 날짜를 적는다.

| ID | 조건 |
|---|---|
| G3-1 | Figma의 `key/` 프레임이 선정된 키스크린과 1:1로 대응한다 |
| G3-2 | 프레임 너비 390, 높이 844 이상 |
| G3-3 | `approval.json`이 있고 결과가 `승인`이다 |
| G3-4 | 컨펌자 이름과 날짜가 비어 있지 않다 |
| G3-5 | 결과가 `반려`면 사유 코드가 정확히 1개 (`scripts/run.py confirm`이 기록 전에 검사) |
| G3-6 | 결과가 `승인`이면 `approval.json`의 Q1, Q2, Q3 답이 전부 `예`다 |

G3-1, G3-2는 멈추기 전에 검사한다. 미통과면 컨펌 요청을 하지 않는다.

## 실패 시 복귀
| 게이트 | 복귀 | 한도 |
|---|---|---|
| G0 | 시작 안 함. 고친 뒤 G0를 다시 판정 | - |
| I-1, I-2 | 없음. 즉시 중단 | - |
| G1 | S1 다시 | 2회. 넘으면 중단하고 리포트 |
| G2 | S2 다시 | 2회. 넘으면 중단하고 리포트 |
| G3-1, G3-2 | S3 다시 | 2회. 넘으면 중단하고 리포트 |
| G3 반려 | 사유 코드에 따라 S3 / S2 / S1 | 없음 |
| G4 | S4 다시 | 2회. 넘으면 중단하고 리포트 |
| S5 | S4로 | 3회. 넘으면 중단하고 리포트 |

게이트 조건, 판정 스크립트, `rules/` 파일은 실행 중에 고치지 않는다. 통과가 안 되면 산출물을 고친다.
