# 하네스 오케스트레이터 (R7)

오케스트레이터는 CLAUDE.md의 지시를 따르는 메인 세션이다. 산출물 내용은 쓰지 않고 순서만 관리한다.

## 실행 순서
1. 트리거를 해석한다 (`harness-roles.md` 트리거 표).
2. `scripts/run.py start`로 실행 폴더, `input.json`, `state.json`을 만든다. 입력이 G0-1, G0-2에 어긋나면 폴더를 만들지 않는다.
3. `judge`에게 G0를 맡긴다. 미통과면 틀린 값을 알리고 멈춘다.
4. 단계마다 반복한다: 작업 에이전트 호출 → `judge`에게 게이트 맡김 → 통과면 다음 단계, 미통과면 같은 단계 다시.
5. S3 뒤 G3-1, G3-2를 통과하면 Figma 링크를 보여주고 멈춘다.
6. 승인이 기록되면 S4 → G4 → S5로 간다.
7. S5 위반이 0건이면 완료를 알린다.

## 멈추는 지점 (3종류뿐)
| 지점 | 보여주는 것 | 기다리는 입력 |
|---|---|---|
| G0 미통과 | 틀린 입력값과 규칙 ID | 고친 `디자인 시작: ...` |
| G3 컨펌 대기 | Figma 페이지 링크, 키스크린 이름 목록 | `컨펌 승인 <이름>` 또는 `컨펌 반려 <코드> <메모>` |
| 재시도 한도 초과 | 남은 위반 목록 (규칙 ID, 화면명, 노드 ID, 실제 값, 허용 값) | 실행자 판단 |

그 밖의 지점에서는 게이트를 통과하면 묻지 않고 다음 단계로 간다.

## 게이트 우회 금지
- 미통과 상태로는 다음 단계에 가지 않는다. 실행자가 넘어가라고 해도 가지 않는다.
- 조건이 틀렸다고 판단되면 실행을 멈추고, `docs/harness-gates.md`를 고친 뒤 판정을 다시 돌린다.
- 조건 수정은 실행 밖에서 실행자 승인을 받아 한다. 에이전트는 조건을 고치지 않는다.
- 우회 기록 기능은 두지 않는다.

## 상태 관리
- `input.json`과 `approval.json`은 `scripts/run.py`가, `state.json`은 `scripts/run.py`와 `scripts/gate.py`가 쓴다. 게이트 결과와 단계 이동은 `gate.py`가 판정 직후 직접 기록한다. 오케스트레이터는 스크립트를 실행할 뿐 파일을 직접 고치지 않는다.
- `state.json` 항목: 실행 폴더명, 현재 단계, 게이트별 결과와 시각, 단계별 재시도 횟수, S5→S4 복귀 횟수, 통과한 단계 폴더의 파일 해시 목록.

## 폴더 제한 (훅)
- `.claude/settings.json`에 파일 쓰기 직전 검사 훅을 등록한다: `scripts/guard.py`.
- 허용: `state.json`의 현재 단계에 해당하는 폴더 1개.
- 차단: `docs/`, `rules/`, `scripts/`, `.claude/`, `state.json`, `input.json`, `approval.json`, 현재 단계가 아닌 단계 폴더.
- 실행 중이 아닐 때(진행 중인 실행이 0개)는 훅이 막지 않는다.
- 훅이 못 막는 경로(셸 명령으로 쓰기)는 게이트에서 잡는다: 통과한 단계 폴더와 `docs/`, `rules/`, `scripts/`의 파일 해시가 기록과 다르면 미통과.

## 스크립트 (Python 3, `scripts/`)
| 파일 | 하는 일 |
|---|---|
| `build_rules.py` | `docs/design.md` → `rules/rules.json` 생성. 값 없는 토큰이 있으면 실패 |
| `run.py` | 실행 폴더 생성, 상태 조회, 컨펌 기록, 반려 시 복귀와 폴더 비우기, 중단된 실행 다시 열기(`retry`), 조건 수정 뒤 다시 묶기(`relock`), 실행 기록 집계(`review`) |
| `gate.py` | `gate.py <G0\|G1\|G2\|G3\|G4\|S5> <실행 폴더>`. 조건을 세고 결과를 `state.json`에 기록한다. 종료 코드 0 통과 · 1 미통과 · 2 컨펌 대기 · 3 판정 불가. G3, G4, S5는 Figma REST API를 직접 읽는다. S5는 `violations.json`, `report.md`도 쓴다 |
| `guard.py` | 훅. 쓰려는 경로가 허용 폴더 밖이면 차단 |
| `test_gates.py` | 판정 스크립트 검증. 통과 기록이 없으면 `run.py start`가 거부한다 |
| `harness_lib.py` | 공용 함수 (해시, 상태 파일, 문서 파싱, Figma 읽기) |

- 의존성: PyYAML 1개.
- 네트워크 접속은 `gate.py`가 Figma REST API(`api.figma.com`)를 읽는 것 하나뿐이다. 읽기 전용이며 Figma를 고치지 않는다.
- Figma 접근 토큰은 환경 변수 `FIGMA_TOKEN`에 둔다. 파일에 적지 않는다.
- `retry`와 `relock`은 실행자가 지시했을 때만 실행한다.

## 완료 시 출력
- 대상 화면 수, 프레임 수, 위반 0건
- Figma 페이지 링크
- `s5-review/report.md` 경로
- S5→S4 복귀 횟수
