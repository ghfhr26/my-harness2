# 하네스 목적 (R2)

## 매번 달라지는 것 (입력)
- 유저스토리 번호: `docs/story-service.md`의 1~5 중 1개 이상
- 대상 화면명: `docs/prd.md` §16 핵심 화면 10개 중 1개 이상
  (홈 / 무료 학습자료 / 유료 멤버 자료실 / 스킬 라이브러리 / 미션 상세 /
   제출 화면 / 내 학습 / 내 자산 / 자산 상세 / 운영자 검수 화면)

## 고정인 것 (입력 아님)
- `docs/prd.md`, `docs/design.md`, `docs/story-service.md`
- 프레임 크기 390×844

## 사용자
- 실행자: 디자이너 1명 (나)
- 컨펌자: 내부 관계자 (유일한 사람 승인)
- 리포트 용어: 토큰명·노드 ID 등 디자인 용어 그대로

## 완료 기준 (한 문장)
입력한 대상 화면 N개가 Figma에 390×844 프레임 N개로 존재하고,
`docs/design.md` 대조 위반이 0건이다.
