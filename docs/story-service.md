# 허들링 앱 유저스토리

출처: `docs/prd.md` (MVP 1차 범위 기준, 구매자 흐름·피드백·수익 내역·허들링 픽은 제외)

## 유저스토리

| # | 유저스토리 | PRD 근거 |
|---|---|---|
| 1 | **무료 학습자**가 **허들링의 AI/Figma/자동화/바이브코딩 콘텐츠를 부담 없이 둘러본다.** | §3-1, §6-1 |
| 2 | **유료 멤버**가 **강의자료, 다시보기, 템플릿, 프롬프트, 스킬 파일, 미션을 한곳에서 확인한다.** | §3-2, §6-2, §6-3 |
| 3 | **AI 실무 실험을 하는 멤버**가 **매달 만든 프롬프트, 스킬 파일, 자동화 템플릿, 업무 적용 사례를 제출하고 기록한다.** | §3-3, §6-4, §6-5 |
| 4 | **판매를 원하는 멤버**가 **내가 만든 자료 중 일부를 골라 판매 신청하고, 그 상태를 확인한다.** | §3-4, §6-5 |
| 5 | **운영자**가 **무료/유료/판매용 자료를 구분해 관리하고, 멤버가 올린 판매 신청 자료를 검수한다.** | §3-6, §6-7 |

## 이 서비스에서 어기면 안 되는 것

| # | 어기면 안 되는 것 | PRD 근거 |
|---|---|---|
| A | 멤버가 만든 자료는 **기본적으로 비공개**이고, 본인이 선택한 경우에만 멤버 공개 또는 판매 신청이 가능하다. | §14 |
| B | 판매 자산은 **운영자 검수를 통과해야 하고**, 개인정보·고객정보·회사기밀·타인의 저작물은 포함될 수 없다. | §14 |
