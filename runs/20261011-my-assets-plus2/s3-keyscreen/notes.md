Figma 페이지 `20261011-my-assets-plus2` (페이지 ID `12:2`)

| 프레임 | 노드 ID | 크기 |
|---|---|---|
| `key/내 자산` | `12:3` | 390 × 1282 |
| `key/자산 상세` | `13:2` | 390 × 1048 |

서체: Noto Sans KR Light / Regular / Medium / Bold 네 굵기 모두 불러왔다. 다른 서체로 바뀐 텍스트는 없다.

## 판단 근거

- **컴포넌트를 만들지 않았다.** 파일에 `Design System` 페이지, 로컬 변수, 텍스트 스타일이 없었다. 키스크린은 컴포넌트 인스턴스가 아니라 `docs/design.md` 컴포넌트명과 설계서 `new:` 이름을 붙인 오토 레이아웃 프레임으로 그렸다. 색·간격·모서리는 토큰 값을 직접 넣었다(변수 연결 없음). 컴포넌트화는 S4에서 정하면 된다.
- **프레임 구조.** 프레임 바로 아래 요소는 전부 좌우를 꽉 채운 섹션(너비 390)이고, 섹션 안쪽에 좌우 패딩 16을 주었다. 섹션 사이 간격은 각 섹션의 위 패딩으로 넣었다.
- **높이.** 버튼·칩·배지·입력란은 높이를 고정하지 않고 최소 높이(48 / 44 / 24 / 96)로 주었다. 실제 높이는 설계서 값과 같다.
- **행간.** 퍼센트 값으로 넣었다(130 / 135 / 140 / 150%).
- **이미지.** 자산 상세의 미리보기(358×200)와 검수 행 썸네일 3개(72×72)는 스크립트로 만든 자리 표시 이미지를 이미지 채움으로 넣었다. 실제 자산 결과 스크린샷이 아니다.
- **꺾쇠와 체크 표시**는 텍스트가 아니라 벡터 선으로 그렸다(서체에 없는 글리프가 다른 서체로 바뀌는 것을 피하려고). "← 내 자산"의 화살표는 Noto Sans KR 글리프로 나온다.
- **하단 고정 바**(자산 상세)는 프레임 맨 아래 마지막 요소로 두었다. 프레임이 844보다 길어 스크롤 고정은 정적 시안에 표현하지 않았다.
- **text-input 레이블과 입력란 사이 간격**은 설계서에 값이 없어 `{spacing.xs}`(8)로 두었다.

## 미정 / 컨펌 때 봐야 할 것

- **선택된 검수 행의 `검수 대기` 배지가 배경에 묻힌다.** 설계서대로 선택된 `review-row`는 `{colors.canvas-soft}` 채움이고 `검수 대기` 배지도 `{colors.canvas-soft}` 채움에 테두리가 없어, 첫 번째 행에서는 배지 모양이 보이지 않고 글자만 보인다. 설계서 값을 그대로 따랐고 고치지 않았다. 고치려면 설계서(S2)에서 선택 행 표현이나 배지 표를 바꿔야 한다.
- 비활성 "승인" 버튼 모양(`{colors.canvas-soft}` 채움 + `{colors.text-faint}` 라벨)은 설계서의 미정 항목 그대로다. 레이어 이름은 `button-primary`다.
- 설계서의 조건부 상태(빈 상태, 필터 결과 없음, `review-notice`, 8/8 체크 등)는 설계서 지시대로 그리지 않았다.
- 설계서 각 화면의 "미정" 항목은 그대로 남아 있다.
- 오케스트레이터는 파일에 다른 실행의 페이지 `20261011-my-assets-2`가 있다고 했지만, 작업 시작 때 파일에는 `Page 1`만 있었다. `Page 1`은 읽지도 고치지도 않았다.
